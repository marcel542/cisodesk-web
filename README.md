# CISO Desk — website

The pages the App Store requires for [CISO Desk](https://cisodesk.lightspeedconsulting.ai):
a privacy policy, a support page and a short overview.

Static HTML and one stylesheet. No build step, no JavaScript, no trackers —
which is the same promise the app itself makes.
